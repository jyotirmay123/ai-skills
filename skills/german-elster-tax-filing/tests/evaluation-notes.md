# Authoring evaluation record

Date: 2026-10-27. All cases synthetic; no taxpayer accounts, credentials or real filings used. Public official sources and a pinned community MCP source were inspected. This record documents observed behavior, not a certification of tax advice.

## Baseline

A fresh evaluator without the new skill already recognized major risks in the complex Germany/India household scenario: stale parameters, invented receipts, cross-border share compensation, acquisition-window repairs, fund receipt-year timing and unsupported submission. It nevertheless cited the joint-determination instructions for a personal capital-income claim. The skill therefore makes citation scope, taxpayer type, assessment year and direct supporting passages explicit, alongside reusable evidence and reconciliation records.

The installer regression test was run before adding the skill and failed because the new skill was absent from the installed directory. After addition, the same test passed; full-directory comparisons verify nested references, metadata and scenarios are copied unchanged for Codex and Claude Code.
